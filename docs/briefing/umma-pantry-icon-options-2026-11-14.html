Pantry icons

Four directions drawn from the Umma brand kit, each applied to the same eight ingredients from a real pantry. These are rough sketches to choose a style, not finished art.

My recommendation

A, Persimmon flat, for pantry rows. It's the only one drawn the way the logo is drawn: flat fills in brand colours, no outlines, details cut out of the shape. Put it next to the app icon and it looks like the same family.

B is the safe fallback if A turns out too busy in long lists. It's the quietest and the closest to Apple's own icons, but it carries the brand only through colour.

What making the set takes

  • How many: about 60 icons for the most common ingredients, plus 14 for the food categories (produce, herb, protein, condiment and so on). Anything without its own icon uses its category's.
  • Format: vector assets in the app's asset catalog. Styles B and C can be tinted by iOS like Apple's own icons. Style A ships in fixed colours, with a second version for dark mode.
  • Who draws them: you, a designer, or generated with an AI image tool and then redrawn into clean vectors. All three follow one written style guide: a 32-point grid, rounded corners and the brand colours.
  • Code: one small backend PR adds an icon name to each ingredient. A second, iOS-only PR draws the icon in the pantry row, Pantry fit and Swaps.

These sketches are drawn in plain SVG. Final icons would get proper optical balancing at 20, 28 and 34 points.
